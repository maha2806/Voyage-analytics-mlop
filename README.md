# ✈️ Voyage Analytics – Integrating MLOps in the Travel Industry

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 🌍 Project Overview

The travel and tourism industry offers significant opportunities for innovation through the integration of data analytics and machine learning. By analyzing travel-related data, businesses can better understand customer preferences, identify travel patterns, and enhance decision-making.

**Voyage Analytics** is a capstone project built around three datasets — **Users, Flights, and Hotels** — each providing valuable insights into different aspects of travel behavior and preferences.

The primary goal is to leverage these datasets to develop and deploy machine learning models that improve predictive capabilities in travel-related decision-making while providing hands-on experience in implementing **MLOps practices**.

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 📖 Introduction

This project focuses on applying data analytics and machine learning techniques to enhance travel and tourism experiences.

Using the Users, Flights, and Hotels datasets, the project aims to develop machine learning solutions for:

- Predicting flight ticket prices.
- Classifying user gender.
- Recommending hotels.

The project also emphasizes deploying these models through practical MLOps implementation.

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 🎯 Project Objectives

1. **Regression Model Development:** Develop a regression model using the flights dataset to predict flight ticket prices.

2. **Streamlit Application:** Create a Streamlit web application that enables users to obtain real-time flight price predictions.

3. **Containerization:** Package and deploy the machine learning model using Docker.

4. **Model Tracking:** Implement MLflow for tracking machine learning experiments and managing model versions.

5. **Gender Classification:** Develop and deploy a machine learning model for classifying user gender.

6. **Travel Recommendation System:** Build a hotel recommendation system and develop a Streamlit application to provide interactive insights.
